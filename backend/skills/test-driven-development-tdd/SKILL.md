# Test-Driven Development (TDD)

## Overview
Disiplin koding Red-Green-Refactor: menuliskan unit test yang gagal terlebih dahulu sebelum mengimplementasikan kode produksi.

## When to Use
Gunakan keahlian ini saat diminta atau mendeteksi tugas dengan kata kunci: tdd, red green refactor, unit test, test first, testing.

## Steps
1. Identifikasi spesifikasi fitur atau bug yang akan diperbaiki
2. Tulis berkas unit test minimal yang mengekspresikan ekspektasi perilaku baru
3. Jalankan test runner untuk memverifikasi kegagalan uji (Red Phase)
4. Tulis implementasi kode minimal hingga pengujian lulus (Green Phase)
5. Bersihkan dan rapikan struktur kode tanpa merusak kelulusan tes (Refactor Phase)
