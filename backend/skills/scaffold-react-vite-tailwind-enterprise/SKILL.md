# Scaffold React Vite Tailwind Enterprise

## Overview
Alur kerja scaffold proyek React modern dengan Vite, Tailwind CSS v4, dan arsitektur folder modular

## When to Use
Gunakan keahlian ini saat diminta atau mendeteksi tugas dengan kata kunci: react, vite, tailwind, scaffold.

## Steps
1. Jalankan npm create vite@latest untuk inisiasi React TS
2. Setup Tailwind CSS v4 via @tailwindcss/postcss
3. Buat struktur folder components, layouts, dan state
4. Uji verifikasi build via npm run build
