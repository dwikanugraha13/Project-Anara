# Systematic Debugging

## Overview
Metodologi pelacakan bug berstruktur: reproduksi masalah, isolasi akar masalah, hipotesis terarah, dan verifikasi perbaikan.

## When to Use
Gunakan keahlian ini saat diminta atau mendeteksi tugas dengan kata kunci: debug, debugging, fix bug, traceback, error, investigasi.

## Steps
1. Reproduksi pesan kesalahan atau kegagalan sistem secara konsisten
2. Telusuri stack trace, error logs, dan baris kode terkait
3. Bentuk hipotesis logis mengenai penyebab kegagalan
4. Buat perubahan minimal untuk menguji hipotesis
5. Jalankan verifikasi menyeluruh untuk memastikan regresi tidak terjadi
