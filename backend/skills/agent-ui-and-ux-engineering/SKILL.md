# Agent UI and UX Engineering

Use this skill when designing, building, modernizing, or auditing AI coding agent interfaces across terminal CLIs, web workspaces, and full-featured desktop IDEs (achieving parity with Google Antigravity, Anara Coding Agent, Cursor, and Anara Agent).

## Core Architectural Invariants

### 1. Liquid Glass Visual Language & Antigravity Aesthetics
- **"Flat, Not Boxed" & Hairline Elevation (Anti Card-in-Card):** Strictly ban nested boxes (cards inside cards) or layered rounded boxes with thick borders. Establish visual hierarchy through generous whitespace, crisp typography, and 1px hairline dividers (`border-white/[0.08]` / `rgba(255,255,255,0.08)` / `#27272a`). Floating elements (popovers, pickers, dialogs) use borderless elevation with subtle ambient falloff shadows rather than heavy generic drop shadows.
- **Canvas & Surface Palette:** Ground the entire workspace in a cohesive dark obsidian void (`#030712` base, `#060913`/90 for navigation and sidebars, `#070b16` for the code editor surface). Never stitch together random mismatched flat blue backgrounds.
- **Frosted Refraction & Specular Highlights:** Apply deep liquid glass styling (`backdrop-blur-2xl` with subtle specular top hairlines: `h-px bg-gradient-to-r from-transparent via-cyan-400/25 to-transparent`). Use hairline dividers (`border-white/[0.08]`) that light up with smooth cyan accents (`hover:bg-cyan-400/50 active:bg-cyan-400`) during drag resizing.
- **Zero Raw OS Emojis in Professional Chrome:** Never place raw platform emojis (`💬`, `📁`, `⌨️`, `🤖`, `+ Baru`) in activity bars, tabs, session pickers, or toolbars. Raw emojis render inconsistently across operating systems and convey an amateur prototype aesthetic. Use razor-sharp SVG vector icons (1.8 stroke width, 14–16px bounding box) paired with subdued micro-typography (`font-mono text-xs font-semibold`).
- **Antigravity Welcome Hub (No Dead Empty States):** When no file is open in the code editor, never render a blank, abandoned gray box. Present a central Liquid Glass Welcome Hub featuring ambient luminous glow orbs (`blur-[120px]`), brand mark, quick-action cards (`Browse Files`, `Terminal Shell`), and keyboard shortcut guide badges (`Ctrl + F`, `Ctrl + S`).
- **Anti-Slop Color Discipline (Zero Rainbow Gradients):** Strictly avoid generic cyan-via-teal-to-indigo or violet glossy rainbow gradients on primary action buttons or send controls (the #1 tell of AI design slop). Use focused, high-contrast luminous single-accent styling (e.g. `bg-cyan-400 hover:bg-cyan-300 text-black shadow-[0_0_14px_rgba(34,211,238,0.4)]` or deep obsidian glass with cyan specular sheen).
- **Framework Dev Widget Suppression:** In Next.js or modern frontend app frameworks, disable framework dev badges (`devIndicators: false` in `next.config.ts`) so persistent circular dev indicators do not hover over and occlude navigation sidebars, session timestamps, or status items.
- **Zero Layout Shift (ZLS) Preload Freeze & Hydration Stability:** In web agent workspaces, prevent flash-of-unstyled-content (FOUC) and layout jumping during SSR rehydration by applying a transition freeze (`html.preload * { transition: none !important; animation: none !important; }`). Pair with synchronous inline `<script>` initialization in `<head>` that synchronizes `localStorage` panel widths (sidebar, file tree, code studio panes) into both CSS custom properties (`--sidebar-width`) and cookies before first paint.
- **Selective Element Scaling vs Global Tag Transforms:** Never apply blanket active CSS transforms like `button:active { transform: scale(0.95); }` on bare HTML element tags. Global scaling distorts tabs, dropdown selectors, floating window controls, and toolbars across the workspace. Restrict micro-scale feedback to dedicated interactive classes (`.pressable:active`, `button.pressable:active`) or explicitly exclude chrome controls (`button:not([role="tab"]):not([data-no-scale]):active`).
- **Decoupled Origin & Dev Environment Configuration:** Never hardcode custom tunnel or staging domains in static framework config (`allowedDevOrigins`). Parse environment variables dynamically (`ALLOWED_DEV_ORIGINS`) with safe local fallbacks (`localhost`, `127.0.0.1`).
- **Next.js App Router Client-Only Dynamic Import Discipline (`React.lazy` vs `next/dynamic` Bailout):** In Next.js 15/16 App Router, calling `next/dynamic(() => import(...), { ssr: false })` inside a Client Component rendered during SSR triggers an explicit runtime exception (`Bail out to client-side rendering: next/dynamic`) that surfaces as a dev error overlay. For client-only components that touch browser-only APIs (e.g. Three.js Canvas, WebGL, AudioContext), use standard `React.lazy(() => import(...))` wrapped in `<Suspense fallback={null}>` and guarded by an `isMounted` mount flag (`useEffect(() => setIsMounted(true), [])`). This guarantees zero SSR execution of window/WebGL APIs and zero Next.js dynamic bailout errors.
- **Reverse Proxy & Cloudflare Tunnel Domain Port Routing:** In dynamic backend and WebSocket URL helpers (`getBackendUrl()`, `getWebSocketUrl()`), strictly check whether `window.location.hostname` is a local address (`localhost`, `127.0.0.1`, LAN IPs) before appending backend port overrides (`:8000`). Public domain names accessed via reverse proxies or Cloudflare Tunnels strictly terminate on standard HTTP/HTTPS ports (80/443); appending `:8000` to a public domain breaks WebSocket handshakes (`wss://<domain>:8000/ws` fails) and triggers mixed-content / connection-refused errors.
- **Chat-First Default Loading over Remote Tunnels (Anti-3D Freeze):** When designing multimodal web workspaces featuring heavy 3D WebGL avatars (20–30MB GLB assets), default the initial workspace interaction mode to lightweight text chat (`"chat"`). Over remote tunnels, constrained mobile connections, or browsers blocking WebGL, defaulting to 3D voice mode traps visitors behind a multi-megabyte download freeze before client-side hydration can complete. Text chat mode renders the complete UI in <300ms with zero 3D asset downloads, lazily initializing the WebGL canvas only upon explicit user activation of voice mode.
- **Deep-Child Hook ReferenceErrors Masked as Page Boundary Crashes:** In modern React App Routers, when an unhandled `ReferenceError` occurs in an inner component's hook or dependency array (e.g. an undeclared variable in a `useEffect` dependency list like `[..., targetId]`), the framework's error boundary unwinds to the root server page component (`app/page.tsx (7:5)`), misleading developers into suspecting page-level routing or cookies. Use headless browser CDP runtime probes (`Runtime.exceptionThrown`) or inspect the dev portal shadow DOM to capture the full call stack and immediately isolate the offending leaf component.
- **React 19 / Next.js 16 Script Tags in Root Layout (`next/script` vs raw `<script>` Console Error):** In React 19 / Next.js 16 App Router, placing a raw `<script dangerouslySetInnerHTML={{ __html: ... }} />` inside a React component (like `<head>` or `<body>` in `app/layout.tsx`) triggers a runtime console error: `Encountered a script tag while rendering React component. Scripts inside React components are never executed when rendering on the client. Consider using template tag instead`. Always use Next.js's official `<Script id="unique-id" strategy="beforeInteractive">` from `next/script` for pre-hydration initialization (e.g. syncing `localStorage` layout metrics to CSS custom properties and cookies).
- **Tunnel ChunkLoadError Timeout & Remote Dev Server Caching Defense (`chunkLoadTimeout` + `Cache-Control`):** When serving Next.js App Router applications over Cloudflare Tunnels, reverse proxies, or high-latency remote connections: Webpack's default chunk loading timeout (120s) triggers `Runtime ChunkLoadError: Loading chunk ... failed. (timeout: ...)` when large unminified dev chunks (2–10MB with eval-source-maps) transfer over the tunnel. Separate Server-to-Client boundaries (`page.tsx` as Server Component importing `HomePageClient.tsx`) force runtime dynamic chunk fetching that is prone to timeout; mark `app/page.tsx` as `"use client"` directly when it serves solely as a client view entry to eliminate artificial chunk-split boundaries. In `next.config.ts`, set `config.output.chunkLoadTimeout = 300000;` (5 minutes) under `webpack`, add dev headers to force `Cache-Control: no-cache, no-store, must-revalidate` on `/_next/static/:path*` to prevent Cloudflare from caching stale development chunks (`max-age=14400`), and conditionally render modal dialogs and IDE drawers (`{isOpen && <Suspense fallback={null}><Component /></Suspense>}`) so secondary code is never bundled into the initial page chunk.
- **Pitfall:** Mixing flat matte surfaces with arbitrary emoji icons breaks visual immersion and makes complex agent workspaces look cluttered, amateur, and disorienting.

### 2. High-Density Agent Console Architecture & Clutter Elimination
- **2 Core Studio Pillars Organization (Anti-Legacy Redundancy):** Consolidate autonomous agent command consoles strictly into 2 high-density developer pillars, eliminating legacy consumer-style manual CRUD tabs:
  1. *Autonomous Agent:* Soul & Rules (`SOUL.md`, `USER.md`, `MEMORY.md`), Tools & Automation (Physical instruments, autonomous task scheduler, sub-agent swarms), and Skills Catalog.
  2. *AI Gateway & Network:* Providers & Keys (multi-provider routing, proxy endpoints, token telemetry) and Integrations & Channels (Telegram, WhatsApp, CLI).
- **Tab State Preservation vs Unmount Destruction:** In multi-tab agent command consoles (Soul & Rules, Tools & Automation, Skills Catalog, Providers, Integrations), never unmount tab components with conditional rendering (`{activeTab === "soul" && <BrainSoulTab />}`). Unmounting wipes active unsaved textarea buffers (e.g. `SOUL.md` or `MEMORY.md` directives) and resets search filters, scroll positions, or pagination. Preserve mounted tab states using CSS display toggling (`className={activeTab === "soul" ? "block h-full" : "hidden"}`).
- **Keydown Listener Churn & Stable Shortcut Handlers:** When registering global keyboard shortcuts (e.g. `Ctrl+S` / `Cmd+S` to save directives in textarea editors), never bind the `keydown` listener in an effect that depends on the raw text buffer state. This causes the event listener to be detached and re-attached on every keystroke, causing event listener churn and dropped input. Back active buffers and tab identifiers with `useRef` (`bufferRef.current = buffer`), keeping the shortcut callback stable (`useCallback` with empty `[]` dependencies) so the window event listener attaches once on mount.
- **Resilient Multi-Endpoint Aggregation (`Promise.allSettled` vs `Promise.all`):** When aggregating multiple independent data streams in console tabs (e.g. Tools catalog, subagent tasks, and autonomous cron schedules), never group requests with `Promise.all`. If one secondary endpoint fails or 404s, `Promise.all` rejects immediately and drops the entire view. Use `Promise.allSettled` to populate available sections independently and handle partial failures gracefully.
- **OAuth Window postMessage Origin Verification & Stable Polling Handlers:** When implementing browser-based OAuth PKCE login flows (e.g. `CodexOAuthModal`), always verify `e.origin === window.location.origin` (or trusted backend origin) before processing completion messages (`CODEX_OAUTH_SUCCESS`) to prevent cross-origin auth injection. Back callback props (`onClose`, `onSuccess`) with `useRef` inside polling modals or wrap them with `useCallback` in parent containers to avoid tearing down and resetting polling timers on parent state re-renders.
- **Zero Cleartext Credential Storage in Browser Caches:** Never dump serialized provider accounts, keys, or tokens into browser `sessionStorage` or `localStorage` (e.g. `anara_cached_providers`). Maintain active provider state strictly in React in-memory state, and verify that client-facing API endpoints (such as `/api/providers/custom`) mask secrets (`include_secrets=False`) to prevent XSS credential exfiltration.
- **Subscription Lifecycle & In-Flight QR Polling Guards:** When live-polling channel pairing status or dynamic QR codes (e.g. WhatsApp bridge handshake), guard state updates with an active `isMounted` flag and cancel intervals on unmount so late-arriving HTTP responses do not update state or reopen unmounted modals.
- **Form Multi-Submission Guards:** Asynchronous provider and account creation buttons must track an `isCreating` / `isConnecting` boolean state to disable submit buttons while requests are in flight, preventing concurrent duplicate database inserts from rapid user clicks.
- **Decoupled Data Contracts vs UI Component Bleed (`types.ts` Anti-Bloat):** Never declare or embed active interactive UI components (`BrandIcon`, `CategoryIcon`, `LiquidGlassSelect`, modals) inside data contract files (`types.ts` / `types.tsx`). Keep `types.ts` strictly for data schemas, union types, and API payloads; import and re-export shared UI components from dedicated component modules (`@/components/ui`) to prevent circular dependencies, bundle bloat, and code drift.
- **KV Cache Hierarchy & Token Telemetry in Directive Editors:** In agent soul and prompt directive editors, display prompt caching tiers alongside character counters (Tier 1: `SOUL.md` Prefix - static, Tier 2: `USER.md` Context - semi-static, Tier 3: `MEMORY.md` Dynamic Tail) and live token approximations (`~${Math.ceil(length / 4)} tokens`) so developers have real-time visibility into cache efficiency and token budgeting as they author directives.
- **V1/V2 Skill Library Synchronization:** When registering agent skills through UI or API endpoints, ensure database inserts (`add_agent_skill`) immediately synchronize to the runtime's filesystem library (`skill_library.save_skill()` generating `SKILL.md` under `skills/<slug>/`). Otherwise, the UI presents a disconnect where newly created skills appear in legacy database lists but are missing from the active skills catalog or CLI discovery.
- **Eliminate Redundant "Memory & Context" CRUD Tables:** In autonomous agents, persistent memory lives natively in Markdown directives (`MEMORY.md`, `USER.md`, `SOUL.md`), tasks are executed autonomously via background schedulers and task scratchpads, and workspaces are indexed dynamically via git boundaries and AST code symbols. Never introduce separate, redundant manual CRUD tabs ("Persistent Memory" SQLite tables, manual consumer to-do checklists, or manual project workspace forms) that duplicate core engine capabilities.
- **Eliminate Consumer Address Books & Manual Contact Books in Channel Gateways:** Channel integrations (Telegram, WhatsApp, Discord) in an autonomous agent are protocol gateways for omnichannel messaging, not consumer phonebooks. Never embed manual address book CRUD forms ("WhatsApp Contacts Book" with nickname/phone input cards) inside the agent network console. Manual contact lists clutter the console and create useless form maintenance.
- **Provider Protocol Badges & Dedicated Brand Iconography (Anti-Lazy Fallback Bug):** In multi-provider AI gateway consoles, never use a static fallback string for provider protocol badges (e.g. defaulting missing cases to `"Claude Direct"` which causes OpenAI Official, Groq, DeepSeek, and OpenRouter to be mislabeled). Map each provider ID explicitly to its actual protocol/type (`gemini` -> `Native SDK`, `claude` -> `Direct API`, `openai` -> `Official API`, `openrouter` -> `Model Router`, `groq` -> `LPU Fast`, `deepseek` -> `DeepSeek API`, `codex` -> `OAuth PKCE`). Provide dedicated SVG vector brand marks and accent colors rather than rendering monochromatic generic box clones.
- **Horizontal Sub-Tab Rails vs Unconstrained Wrap:** Segmented sub-tab button groups inside hero cards (e.g. `Tools Catalog`, `Autonomous Tasks`, `Sub-Agent Swarms`) must use an overflow-x scroll container (`overflow-x-auto no-scrollbar shrink-0`) rather than unconstrained `flex-wrap`. Unconstrained wrap causes the last sub-tab to break onto a second line alone, creating an awkward visual void.
- **Equal-Height Grid Cards (Anti-Staircase Grid):** Multi-column tool and skill cards must enforce `items-stretch` on the grid and `h-full flex flex-col justify-between` on card containers so cards with differing description lengths align their bottom actions, category tags, and borders symmetrically across rows.
- **Strict UI Language Consistency & JSX String Entity Hygiene:** Never mix languages within adjacent UI controls (such as `Semua (54)` right next to `Active (54)` and `Inactive (0)`, or `Pemicu:` in an English UI). In JSX string literals, never write HTML entities like `&amp;` inside double quotes (e.g. `"read &amp; send messages"`), as React treats string literals literally and renders `&amp;` on screen. Use bare `&` in strings or JSX entity expressions `{"&"}`.
- **Single-Developer Zero-Friction Identity:** In developer coding agents, eliminate complex speaker/voice-profile dropdowns and multi-profile selectors from the UI. User identity and coding preferences belong in `USER.md` (shared automatically across CLI, Web, and desktop).
- **Eliminate Raw Log & Transient Animation Dumps:** Never clutter agent consoles with raw conversation table dumps (redundant with the main chat timeline and session picker) or manual 3D gesture triggers in code environments.
- **High-Density Sidebar Action Toolbar:** Never stack 3+ full-width action buttons vertically in the navigation sidebar (`Brain`, `Code Studio`, `New Chat`). Consolidate into a compact, single-row high-density toolbar: a primary `+ New Chat` button (flex-1) flanked by compact icon buttons (`✦ Brain`, `‹/› Code Studio`) with crisp tooltips.
- **Compact Developer Sidebar Proportions & Single-Row Density (Anti-Inbox Card Syndrome):** Never lock the left navigation sidebar to an oversized width (e.g. 380px min-locked) or wrap every session item into a multi-row bordered card (height ~70px with stacked subtitles and big pill badges). This mimics a mobile messaging inbox rather than an IDE. Set default sidebar width to 260px (min 200px resizable) and format session items as sleek, compact single-row list items (~32px height, `py-1.5 px-2.5 rounded-lg`): transparent by default with hover highlights, subtle active glass state (`bg-white/[0.08]`), single-line title with channel icon, quiet timestamp on the right, and hover-only options menus (`...`). Keep message counts in tooltips rather than distracting high-saturation pill badges.
- **Humanized Session Metadata & Channel Badges:** Never expose raw internal database channel identifiers or bracketed session slugs (e.g. `[telegram:7024711852]`, `[channel:...]`) in session titles. Extract human display names, render crisp SVG platform badges (Telegram, CLI, Web), filter empty duplicate CLI sessions (0 messages), and enforce grammatical pluralization (`1 msg`, `N msgs`).
- **Unblocked Mission Control Views (Zero Identity Blocker Screens):** In autonomous agent command consoles (Memory Vault, Task Scratchpad, Workspace Contexts), never gate or block entire views behind optional biometric attributes or active speaker states (`!activeSpeaker`, `speakers.length === 0`) with blocking screens like "Awaiting User Identification" or "Enable microphone to introduce yourself". A developer orchestrator must provide immediate, open access to persistent memory nodes, project contexts, and task lists across all sessions without requiring voice profiles.
- **Studio Breadcrumb & Mission Header in Modals:** In multi-tab agent command consoles, the right content panel must not leave the top bar empty with only right-aligned Sync/Close buttons. Anchor a clear Studio Breadcrumb Header: section category (`Autonomous Agent` / `AI Gateway & Network`), active tab title, and a one-line capability summary paired with live database connectivity status (`SQLite Connected`). Ensure tab labels in the left rail match the breadcrumb titles exactly (e.g. `Providers & Keys` and `Skills Catalog`) to maintain 100% visual consistency.
- **Obsidian Liquid Glass Modal Framing & Refraction Physics:** Avoid dated 2021 milk-glass effects (heavy 0.22 white borders, 0.65 insets, and rainbow tech gradients) as well as heavy animated background blur circles (`blur-[160px] animate-liquid`) that cause GPU layer thrashing and wash out text contrast. Style modal frames in deep cosmic obsidian (`#060913`/90 void, `#080d1a`/80 backdrop panels), hairline borders (`border-white/[0.10]`), subtle top specular reflections (`h-px via-white/[0.15]`), an inset hairline bevel (`shadow-[inset_0_1px_0_rgba(255,255,255,0.10)]`), restrained radial specular sheen, and precision cyan active indicator notches (`w-1 rounded-r bg-cyan-400 shadow-[0_0_8px_rgba(56,189,248,0.8)]`).
- **Single-Layer Code Studio Canvas vs Double-Card Nesting:** In directive and configuration editors, eliminate card-in-card nesting (avoid wrapping the file switcher in a card and the editor in another card underneath). Place flat segmented glass pill switchers directly on the canvas toolbar (`SOUL.md`, `USER.md`, `MEMORY.md` without verbose parenthetical labels). Integrate a discrete character capacity progress micro-bar (`1,420 / 2,200 chars`), proportional typography (`text-[13px] leading-[1.65] font-mono text-slate-100`), and quiet telemetry footers instead of conversational privacy disclaimers.
- **Pitfall:** Redundant speaker profile selectors fragment memory across arbitrary names and cause split-brain context loss when users inadvertently switch profiles. Raw message log tables create visual noise and degrade console render performance. Oversized multi-tier cards in sidebars waste vertical screen real estate and make desktop workspaces feel like cluttered mobile apps. Gating console tabs behind voice identification blocks web/IDE developers from inspecting and managing their own persistent memories and workspace tasks. Retaining manual memory/todo/project CRUD forms in an autonomous agent confuses users and conflicts with native file-based directives (`MEMORY.md`) and autonomous background task execution. Nested cards and oversized blur balls degrade visual clarity and reduce framerates.

### 3. Interactive Terminal TUI & Live Streaming Parity
- **Live Token Streaming:** Stream model response tokens in real-time within clean unicode framing (`StreamTokenRenderer`), completely eliminating 10–30 second silent pauses while waiting for full model turn completions.
- **In-Place Animated Tool Spinner & Step Chaining:** Render active tool execution using animated braille dots and a live elapsed stopwatch via in-place carriage return rewrites (`\r`). When multiple tools execute in sequence, always complete the preceding tool (`finish_tool(True)`) before spinning up the next one so intermediate tools print their duration and green checkmark (`✓`) rather than being silently overwritten.
- **Interactive Shell Navigation & Dynamic Directory Completer:** Provide persistent history (`~/.<agent>/cli_history`), multi-line editing, and tab-autocompletion for slash commands and workspace `@path` triggers. When completing paths inside subdirectories (e.g. `@backend/c`), preserve directory prefixes (`clean_sub/item/`) and compute replacement offsets against the full typed prefix so folder paths are never dropped down to bare root filenames.
- **Dynamic Workspace Root Anchoring:** Never hardcode the CLI workspace to the agent's install directory. Dynamically resolve `os.getcwd()` and probe upwards for the nearest `.git` boundary. Anchor autocompletion, status HUDs, diff viewers, and session file attachments to this resolved project root.
- **Pre-Flight File Grounding (`@file`):** Detect `@path` references in CLI prompts before model dispatch, read existing file contents up to budget, and attach them into structured prompt context. This gives the model immediate ground-truth context without wasting initial turns calling file read tools.
- **Unified Diff Rendering (Zero Double-Diffing):** When rendering `/diff` or tool patch previews, check whether the payload is already a raw unified diff (`diff --git`, `--- `, `+++ `). Route raw diffs directly to the syntax highlighter (`Syntax(..., "diff")`). Never pass an existing unified diff into `difflib.unified_diff`, which erroneously prepends `+` to every line, turning deletions into `+-` and additions into `++`.
- **Terminal Buffer Adaptation & Screen Buffer Resilience:** On Windows hosts, `prompt_toolkit` defaults to Win32 console buffer APIs (`Win32Output`). In modern terminal emulators (Git Bash, MSYS2 mintty, Windows Terminal, VS Code subshells, or piped subprocesses), this triggers fatal `NoConsoleScreenBufferError: Found xterm-256color, while expecting a Windows console`. Check `sys.stdin.isatty()` before instantiating interactive terminal sessions, provide safe fallback from `create_output()` to `Vt100_Output.from_pty(sys.stdout)` or thread-delegated `input()`, and bypass interactive session setup entirely in single-prompt mode.
- **Non-Blocking Async Prompt Ingestion:** Within `asyncio` event loops, avoid synchronous `session.prompt()` calls that block the loop or generate unawaited coroutine warnings (`RuntimeWarning: coroutine 'Application.run_async' was never awaited`). Always use `await session.prompt_async(...)` or `await asyncio.to_thread(input, ...)` for seamless, non-blocking turn ingestion.
- **Smart Argv Dispatch (Subcommands vs Prompts):** When pairing administrative subcommands (`daemon`, `skills`, `gateway`, `autostart`) with direct prompt execution in an agent CLI runner, do not attach an optional positional prompt argument to a top-level `argparse` parser containing `add_subparsers()`. Subparsers greedily consume the first positional token, causing free-form queries (e.g. `<agent> "hello world"`, `<agent> create a script`) to fail with `invalid choice` errors. Inspect `sys.argv[1:]` prior to parser invocation; if the first non-flag token does not match `KNOWN_SUBCOMMANDS` and is not `--help`/`-h`, route directly to single-prompt execution.
- **Graceful Turn Interruption:** Trap `KeyboardInterrupt` (`Ctrl+C`) during active model streaming or tool execution to abort solely the in-flight turn, releasing terminal spinners cleanly without killing the process or corrupting session history.
- **Pitfall:** Passing git diffs into `difflib.unified_diff` creates corrupted "diff-of-a-diff" displays, while string slicing in completers without directory tracking wipes out subfolders on TAB completion. Unanchored workspace roots cause CLI commands to operate on the agent codebase instead of the user's intended target project.

### 4. Web Chat & Reasoning UX Discipline
- **Zero Redundant Top Micro Header Bars in Web/Desktop Chat Streams (Full-Bleed Timeline & Keyboard-First Chrome):** Never place a static top micro bar (e.g. `Chat · <Speaker> | [Command ⌘K] [Editor Ctrl+\]`) above the main chat timeline in desktop/web workspaces. The browser window title or sidebar already anchors active session identity, and physical buttons for commands or editor toggling consume vertical viewport height without adding utility. Keep high-frequency workstation actions (`Ctrl+K` command palette, `Ctrl+\` split editor toggle, `Ctrl+`` terminal toggle) strictly keyboard-first via global keydown listeners in the background, allowing the message timeline to run completely full-bleed to the top of the canvas for maximum readability and zero chrome clutter.
- **ScaffoldRow vs Boxed Card-itis on Scaffolding Items (Anara Desktop Parity):** Never wrap conversational scaffolding items (Thinking/Reasoning disclosures, Tool execution rows, File edit diffs, Task checklists, File exploration groups) inside heavy rounded rectangle cards (`rounded-lg bg-[#070b14]/75 border border-white/[0.08] shadow-[...] backdrop-blur-xl`) with specular top bars. In Tier-1 agent workbenches (Anara Desktop `DESIGN.md`), these items at rest are **scaffold lines** (`ScaffoldRow`): clean, quiet, single-line text items that sit directly in the transcript flow (`● Thinking (1.2s) ›`, `● Thought for 1.2s ›`, `● Edit file.ts +12 -3 ›`, `● Run npm test (0.4s) ›`). Only when clicked to expand does an inset panel open below the line (e.g. diff gutter table, terminal output box, or flush thinking text with `border-l border-white/10 pl-3`).
- **Single Source of Truth for Thinking Indicators & Elimination of Duplicate Stutter:** Never render a generic text loading placeholder (`<span className="animate-ping" /> Thinking...`) concurrently with a reasoning disclosure component (`ThinkingDisclosure` / `ThinkingCard`). If model reasoning is active or has finished, the disclosure row itself is the sole indicator. The generic placeholder renders strictly when NO text, NO reasoning, and NO active tool progress exists. Once reasoning tokens or text tokens arrive, the generic placeholder must immediately disappear.
- **Zero Synthetic / Fake Thought Events from Orchestrator Runners:** Agent execution runners and orchestrator loops must never inject synthetic or fake thought events (e.g. yielding `TurnEvent(type="thought", content="Processing request in BUILD mode with model ...")`). Fake thought events leak internal orchestration, routing paths (`9router/...`), and developer plumbing into the UI as fake AI cognition. Reasoning disclosures must be reserved exclusively for genuine chain-of-thought (CoT) tokens emitted by reasoning models (e.g. `<think>` blocks, reasoning deltas).
- **Composer Pill Restraint & Collapsed Modality Hygiene:** Never crowd the collapsed model selector button in the bottom composer dock with bright multi-colored modality badges (`[IMG] [VID]`) that compete for visual attention. Adhere to Anara Desktop restraint: format the active dock trigger as a clean obsidian button (`● Model Name ⌄`), reserving modality capability tags (`IMG`, `VID`, `THINK`, `AUD`) and context budgets strictly for the expanded model catalog dropdown.
- **Anchored Composer Dock vs Fixed Overlay Occlusion:** In chat/workbench mode, never place composer input docks as `fixed` floating overlays directly over the timeline without layout containment. Floating docks invariably occlude the AI's bottom response lines, token metrics, or code blocks when users scroll. Structure the chat column as a strict flex container: the timeline takes `flex-1 min-h-0 overflow-y-auto`, and the composer dock is anchored in-flow (`shrink-0 embedded={true}`) at the bottom. Messages naturally stop above the dock divider, guaranteeing 100% text readability without fragile calculated height spacers.
- **Seamless Composer Surface & Zero Internal Divider Lines:** Inside an agent's composer prompt card, never introduce arbitrary horizontal dividing borders (`border-t border-white/[0.07]`) separating the textarea input from the bottom action buttons (`[+]`, `[Model]`, `[Send]`). This breaks the monolithic obsidian glass card into two awkwardly chopped boxes and conveys a clunky template feel. The card surface must be a unified continuous liquid glass plane where the input flows naturally into the action toolbar (`pt-1` without `border-t`). Similarly, eliminate harsh external container borders (`border-t border-white/[0.08]`) across the entire screen right above the floating prompt card. Let the dock card float naturally on a transparent background with zero bounding lines.
- **Direct Canvas Stream vs "Card-itis" (Anti-Slop Archetype):** Never wrap assistant narrative text inside boxed, bordered cards with heavy padding, backdrop blur, drop shadows, and internal `border-t` dividers. Wrapping simple 1-line responses (such as "Action plan expired") inside an isolated card turns dialogue into awkward alert widgets. Assistant text must flow directly on the dark canvas (`text-slate-200 text-[13.5px] leading-relaxed font-sans`). Reserve bordered cards strictly for interactive tools, code diffs, and question forms.
- **Symmetric Developer Prompts vs Skewed Chat Bubbles:** Avoid mobile-messenger style speech bubbles (`rounded-tr-sm` with heavy 20%+ specular gloss and iOS drop shadows). - **Universal Model Display Name Formatting:** Never expose raw routing slugs (e.g. `9router/ag/gemini-3.8-flash-high`) in UI chips or headers where they truncate mid-word (`ag/gemini-3.8-flash-hig…`). Concurrent smooth animation curves interrupt each other, causing severe viewport jitter, CPU spikes, and disrupted reading. Auto-scroll during active streaming must use instant direct DOM assignment (`scrollContainer.scrollTop = scrollContainer.scrollHeight`); reserve `behavior: "smooth"` strictly for explicit user clicks on a floating "Scroll to bottom" button.

Differentiate lifecycle events (`agent_action_start` vs `agent_action_complete`); append each new start event so that multiple consecutive read/search operations are preserved and grouped cleanly into an exploration summary (`Explored 3 reads, 2 searches ▾`).
- **Progressive STT Sentence Prefix Reconciliation:** In streaming speech-to-text reconciliation (`mergeTranscriptText`), never replace existing text simply because the first word matches (`incWords[0] === exWords[0]`) and incoming has more words. That heuristic causes catastrophic data loss whenever a user utters two distinct consecutive sentences starting with the same common word. Verify that ALL words of existing text form an exact prefix of the incoming sentence (`allPrefixMatch`) before treating the incoming chunk as a progressive revision.
- **Kanonical Single Session Storage Key Authority:** Never maintain split-brain dual keys in `localStorage` (such as `anara_active_session_id` vs `anara_active_chat_session_id`). Conflating session storage keys leads to restoration failures on browser refresh and race conditions with WebSocket sync. Standardize on one single canonical key everywhere (`anara_active_session_id`).

Dictating tool names couples UI to backend implementations and breaks when tools are provided dynamically via MCP or renamed. Use declarative, goal-driven execution instructions ("Implement all required files, components, and logic systematically according to the approved plan").
- **Dynamic Plan Completion & Artifact State Contracts:** In agent plan lifecycle state machines, never couple plan completion to specific backend tool name strings (e.g. `payloadToolsUsed.includes("create_zip_archive")`). Trigger plan completion dynamically upon delivery of any verified visual artifact (`visualType === "document_viewer" || visualType === "code_viewer"`) or through structured backend lifecycle status updates (`planStatus === "completed"`).
- **Interactive Question Wizards & Collapsible Timeline Records:** In human-in-the-loop clarification workflows (such as question prompts), active multi-step question wizards belong in the input dock/composer context for high-focus interaction. Once answered or dismissed, render the questionnaire in the chat timeline as a clean, collapsible accordion summary (`X questions answered ▾`) with individual Q&A rows, preventing dead or duplicate interactive forms from cluttering dialogue history.
- **Pre-Allocated Turn Footers & Zero Layout Shift (ZLS) on Stream Completion:** Never conditionally render message turn footers (copy buttons, timestamps, model tokens) with `{!item.isStreaming && footerElement}`. When streaming concludes, popping the footer into the DOM causes an abrupt 28–32px layout shift that disorients the reader. Pre-allocate the footer space permanently with `min-h-[28px]` and `opacity-0 group-hover/turn:opacity-100 transition-opacity`, keeping it invisible during streaming but reserving layout dimensions for strictly zero Cumulative Layout Shift (0 CLS).
- **Passive Wheel Listener for Stream Scroll Interruption (Zero Scroll Hijacking):** Auto-scrolling to bottom during live token streaming must not hijack or fight user wheel interactions. Attach a passive `wheel` listener to the scroll container: any upward scroll (`deltaY < 0`) immediately disengages auto-follow mode (`isFollowingRef.current = false`) and marks incoming tokens as unread on the floating scroll-down FAB (`hasUnread`). Scrolling back near the bottom (<80px) re-engages follow mode seamlessly.
- **Streaming Fences Remend vs Artificial Typewriter RAF Parsing Loop:** In real-time markdown streaming, never slice text by character increments in a 60 Hz `requestAnimationFrame` loop that re-parses the entire document AST 60 times per second. Streaming chunks already arrive progressively over WebSocket. - **4-Stage Interactive Plan State Machine (Pending -> Approved -> Executing -> Completed):** In agent execution plans, never collapse approved, executing, and completed states into a coarse boolean (`isApproved`). Distinguish all 4 states so the UI reflects live progress (`EXECUTING ARCHITECTURE`), renders animated SVG radar indicators on active steps, enables keyboard toggling (`role="checkbox"`, `tabIndex={0}`), and converts file links into semantic buttons triggering the IDE pane.
- **Pitfall:** Wiping thinking text on the first stream delta permanently destroys visibility into model reasoning for thinking models (Claude 3.7 Sonnet, DeepSeek R1, Gemini Flash Thinking), while un-gated auto-scroll violently hijacks the user's viewport during active reading. High-frequency smooth scrolling locks up browser layout engines during rapid token arrivals. Floating docks over scroll containers bury bottom responses under frosted glass. Repeating model banners above every turn produces visual fatigue and template clutter. Boxing assistant narrative into cards turns clean text streams into awkward alert widgets. Coupling plan completion to hardcoded tool strings breaks autonomous execution when MCP or alternative tools are used.

### 5. Code Studio IDE Viewport & Editor Discipline
- **Explicit Code vs Diff View Modes:** Never permanently lock the editor viewport into a unified diff view mode (`unifiedMergeView`) simply because a file is non-empty. Default to clean editable `Code` view; render an explicit interactive toggle `[Code] ↔ [Diff (+X -Y)]` only when the active buffer differs from the disk/original content.
- **Strictly Read-Only Diff Mode:** When mounting unified merge views (`unifiedMergeView`), always lock the editor into read-only mode (`EditorView.editable.of(false)` and `EditorState.readOnly.of(true)`). Never allow users to inadvertently type into or corrupt diff decorations.
- **In-Memory Dirty Buffer Storage vs Synchronous Storage Freezes:** Never serialize full file buffer contents synchronously into `localStorage.setItem` inside an `onChange` or `[editedContents]` effect on every keystroke. `localStorage` is synchronous on the browser main thread and has a strict 5MB quota; typing in 30–50KB files causes typing latency, UI micro-stutters, and triggers `DOMException: QuotaExceededError`. Keep dirty edits in React in-memory state, and debounce session-level persistence (1500ms delay) into `sessionStorage` or IndexedDB.
- **Scoped Keyboard Shortcuts (Anti-Hijacking):** Never register global `window.addEventListener("keydown")` listeners for `Ctrl+F` or `Ctrl+H` without checking focus context. Verify whether the active element is an input outside the IDE (such as the chat input prompt or bottom dock). If user focus is in another input outside `editorContainerRef.current`, pass through native events rather than intercepting focus into the editor search widget.
- **Multiset Frequency Diff Accounting:** Avoid naive `Set`-based line diff calculations, which collapse duplicate identical lines (such as closing braces `}` or blank lines). Use multiset / frequency maps to count added and deleted lines accurately.
- **Stale Closure Drag Resizing:** When implementing draggable panel dividers, avoid referencing React state variables inside `useEffect` mouse event listeners without ref-backing. Track live coordinates and dimensions in `useRef` and read from refs on `mouseup` before persisting to `localStorage` and cookies, eliminating stale-closure revert bugs and reducing re-render churn during 60 FPS dragging.
- **CodeMirror Multi-Tab State Isolation (`key={filePath}`):** When hosting multiple open file tabs in a single editor pane, never mount `<CodeMirror>` without `key={filePath}`. Without file-keyed identity, CodeMirror's undo/redo history stack (`history()`), cursor position, scroll offset, and editor state bleed across files.
- **Unsaved Changes Tab Closure Guard (Data Loss Prevention):** When prompting users to save before closing dirty tabs, never eagerly delete modified buffers from state or close tabs before verifying that the save operation succeeded. Wrap save calls in `try/catch` and verify truthy resolution; keep dirty tabs and buffers intact if saving throws or returns `false`.
- **CRLF Normalization in Line Diff Calculation:** On Windows systems, files on disk often use CRLF (`\r\n`) while browser code editors normalize text to LF (`\n`). Comparing lines by splitting on `\n` without stripping carriage returns (`\r`) flags identical lines as completely modified, generating 100% false-positive diff counts. Normalize both original and active buffers by stripping `\r` before diff multiset frequency analysis.
- **Pitfall:** Initializing diff view on every non-empty file without a toolbar toggle traps users in read-only diff mode, while closures over state in mouseup listeners cause custom layout panel dimensions to snap back to defaults on reload. Un-debounced `localStorage.setItem` on every keystroke causes catastrophic UI freezing in web IDEs. Lack of `key={filePath}` on CodeMirror corrupts undo stacks across tabs, and unverified save-and-close routines wipe user code buffers on network or disk failures.

### 6. Terminal & Process Supervision Architecture
- **Subprocess Lifecycle & Zombie Leak Prevention:** In SSE or HTTP streaming terminal runners, always wrap child process execution in a `finally:` block that terminates unfinished processes (`if proc and proc.returncode is None: proc.kill(); await proc.wait()`). Client aborts (`fetch` connection drop) raise `GeneratorExit` or `asyncio.CancelledError`; without a `finally:` kill, background builds, servers, or loops remain orphaned zombie processes on the host OS.
- **Real Hunk Parsing for Accurate Diff Line Numbers:** Never calculate diff table line numbers from the arbitrary array index of the diff string (`i + 1`). This presents misleading line numbers starting at 1 regardless of where in the file modifications occur. Parse standard unified diff hunk headers (`@@ -oldStart,oldLen +newStart,newLen @@`) to compute and display true original (`oldLine++`) and modified (`newLine++`) line numbers with dedicated styling for hunk headers.
- **Independent Terminal Drawer Decoupling:** Never couple the terminal drawer mount state to an open editor file or inject fake placeholder files (such as `terminal.sh`) to force layout rendering. The terminal panel must render independently at the bottom of the workspace regardless of whether a file is currently active in the editor.
- **Session-Qualified Checkpoint Reversion:** Destructive checkpoint rollback requests must always include the active `session_id` and require an interactive confirmation prompt. Relying on global fallback session state causes rollback requests in one session to overwrite the active worktree of a different concurrent session.
- **Safe ANSI Sequence Handling:** Terminal log viewers must parse or strip raw ANSI escape sequences (`\u001b[...]`) to prevent visual artifacts and terminal control corruption in web displays.
- **Monotonic Tab Sequence (Zero Key Collisions):** Never derive tab IDs from array length (e.g. `term-${tabs.length + 1}`). Closing an intermediate tab causes subsequent creations to reuse existing IDs, triggering React key collisions and tab switching failure. Use a monotonic counter (`useRef(tabs.length)`) or unique session keys.
- **Independent Execution Tracking Per Tab:** Never bind shell input disabled state to a single global `isExecuting` boolean. One tab running a long process (server, build) freezes user input across all other terminal sessions. Track running state in a map or set keyed by tab ID (`executingTabs[tabId]`).
- **Terminal Shell Command History Navigation:** Implement standard terminal keyboard history navigation (`ArrowUp` / `ArrowDown`) with dedicated buffer indices so users can recall and edit previously executed shell commands without retyping.
- **Single Source of Truth for Visual Artifact Projections (Chat vs HUD):** In multimodal agents that project work artifacts across both dual-pane Chat timelines and Voice/3D Avatar HUDs, never duplicate action card, diff viewer, or checklist implementations between chat and HUD components. Reuse the canonical `AgentToolCard` and checklist components across both viewports, eliminating logic drift, ensuring unified rollback checkpoints, and pruning dead prototype cards.

- **IME Composition Guard (Anti-Premature Submit):** On multiline composer inputs, intercepting `e.key === "Enter" && !e.shiftKey` without checking `if (e.nativeEvent.isComposing || (e as any).isComposing || e.keyCode === 229) return;` causes CJK (Chinese, Japanese, Korean) or accented IME candidate selection to prematurely dispatch incomplete raw phonetics to the agent.

Separate the model selector button from the reasoning effort control. Place a dedicated, adjacent `ReasoningPill` (`[Think: Med ▾]`) that conditionally mounts *only* when the active model supports reasoning (`isReasoningSupported(m)`). Store reasoning effort preferences in a per-model dictionary (`localStorage.anara_model_reasoning_efforts` JSON `{ [modelId]: effortLevel }`), ensuring that switching models immediately restores each model's independent reasoning depth without overwriting other models.

Expose standardized, quiet micro-chips (`TXT`, `VISION`, `VIDEO`, `AUDIO`, `THINK`) derived dynamically from backend capability introspection (`supports_vision`, `supports_video`, `supports_audio`, `supports_reasoning`). On the active dock model button, project subtle modality indicators (e.g. `Gemini 3.8 Flash [IMG] [VID]`) so users immediately know whether image or video attachments are supported before sending prompts.
- **Anti-Slop Color & Font Discipline on Status Pills (Zero Pulsing Neon Glow):** Never wrap reasoning pills or status chips in vibrating neon glow effects (`shadow-[0_0_12px_rgba(192,132,252,0.12)]`) or looping `animate-pulse` animations (the archetypal hallmark of AI slop). Adhere strictly to the Anara / Anara Coding Agent obsidian standard: neutral hairline specular borders (`border-white/[0.08]` with hover `border-white/[0.16]`), deep obsidian backdrops (`bg-[#090d16]/98`), crisp static status dots (`bg-purple-400`, `bg-cyan-400`, `bg-zinc-600`), and restrained monospace typography (`text-xs font-mono font-medium text-zinc-300`).

If a model's API tops out at `High` (e.g. Google Gemini API ceiling ~24K tokens or OpenRouter `high` tier max; OpenAI o-series strictly accepting `low`, `medium`, `high`), offering `Max` or `Ultra` is dishonest and triggers upstream HTTP 400 Bad Request errors or silent downgrades. Restrict rendered popover options strictly to the model's supported levels (e.g. Gemini = `["off", "low", "medium", "high"]`). When switching from an `Ultra` model to a lower-ceiling model, monotonically clamp the active level down to the highest supported tier (`"high"`) and synchronize storage immediately, ensuring the UI truthfully displays `Think: High`.
- **Tabular Single-Line Model Selector vs Cluttered 3-Row Stacking (Anara Desktop & Anara Coding Agent Command Palette Parity):** Never render model selector dropdown items as oversized multi-row boxed cards (e.g. 3 stacked vertical rows per model: row 1 name/check, row 2 modality badges, row 3 provider/context metrics, ballooning row height to 75px and causing vertical visual clutter). Follow Anara Desktop (`model-picker.tsx`) and Anara Coding Agent command-palette layout: format each model as a sleek single-line tabular row (~32px height) with active indicator dot, clean model name, and subtle route/vendor tag on the left, and micro-tags (`IMG`, `VID`, `THINK`, `AUD`), context budget (`1M`, `128K`), and checkmark aligned horizontally on the right. Without container checking, clicking the button or its text triggers `onWindowClick` on the exact same frame, immediately closing the popover in 0ms. Tag interactive dropdown roots with `data-dropdown-root="true"` and guard the window listener: `if (target?.closest?.("[data-dropdown-root]")) return; closeDropdown();`.

Native DOM events continue bubbling up to `window`, triggering `onWindowClick` on the very same frame and instantly closing the popover before it can render. Always call `e.nativeEvent?.stopImmediatePropagation?.()` in toggle click handlers to ensure the click event does not reach the window listener.
- **High-DPI HTML5 Canvas vs DOM Churn for Audio Waveforms:** Never drive audio meter bars using 6+ CSS `<span>` elements whose heights update via React state at 30–60 FPS. This produces severe React reconciliation churn and garbage collection spikes. Render live microphone RMS meters to an HTML5 `<canvas>` using `requestAnimationFrame`, scaling with `window.devicePixelRatio`, and cleaning up with `cancelAnimationFrame`.
- **Reasoning Effort & Token Context Surface:** For models with configurable reasoning (Claude 3.7 Sonnet Extended Thinking, OpenAI o-series, DeepSeek R1, Gemini Flash Thinking), expose an inline segmented control (`low` / `medium` / `high`) and display token context window limits (`128k`, `200k`, `1M`) directly on model picker cards rather than leaving users blind to thinking budgets or token limits.
- **Actionable Plan State Machine:** Never treat plan checklists as inert display widgets. Wire status states (`pending_approval`, `executing`, `completed`) with explicit action buttons (`Approve & Run`) and allow immediate execution upon user confirmation.
- **Phantom Scrollbars on Empty Auto-Resizing Inputs:** Never leave `overflow-y-auto` permanently enabled on auto-resizing composer textareas when `minHeight` is smaller than the calculated single-line height (`vertical padding` + `font-size * line-height`). Even when completely empty, sub-pixel calculation mismatches cause browsers to paint an unsightly vertical scrollbar with stepper arrows. Always enforce conditional overflow: `isInputOverflowed || isInputExpanded ? "overflow-y-auto" : "overflow-hidden"`, and set default `minHeight` (e.g. `36px`) safely above single-line height.

Provide explicit, decoupled boolean props (`showInteractionModeToggle`, `showAgentModeToggle`). Scope Plan/Build toggles strictly to specialized coding environments (e.g. Code Studio IDE), while preserving Voice vs Chat mode switching in the main conversation workbench.
- **Pitfall:** Overloading `embedded` to hide mode switchers breaks Voice/Chat navigation when anchoring a dock to fix text occlusion, while unconditional `overflow-y-auto` paints broken native scrollbars on empty textareas. Lack of IME guards sends broken phonetic fragments on Enter, unrevoked blob URLs leak gigabytes over long sessions, and un-debounced height reads stall input response times to single-digit FPS.

### 8. Session Branching, Workspace Tree & Dialog Concurrency
- **Session Branching / Forking Protocol:** Enable users to fork any conversation into an independent parallel branch (`fork_session`). The fork must perform a deep copy of conversation turns, metadata, and active project workspace files to an isolated directory so the user can experiment or pursue alternative implementation plans without corrupting the root session. The UI must expose an explicit `"Branch / Fork"` action in session context menus and immediately transition active focus to the newly spawned branch.
- **Non-Blocking In-App Dialogs vs Main-Thread Freezing `window.confirm()`:** Never invoke synchronous browser modal dialogs (`window.confirm()`, `window.alert()`, `window.prompt()`) for destructive actions like checkpoint rollback, session deletion, or workspace clearing. These freeze the JavaScript main thread, halt Three.js animations, drop WebWorker messages, and fail silently in headless/webview environments. Use inline 2-step confirmations or accessible non-blocking modal overlays.
- **High-Frequency Splitter Drag Throttling (Mousemove vs Mouseup):** Never write synchronously to `localStorage.setItem` or `document.cookie` inside high-frequency `mousemove` handlers (such as splitter/dock resize drag). High-frequency synchronous disk I/O and cookie parser execution drops frame rates from 60 FPS to stutter. Update CSS custom properties or inline styles on `mousemove`, and defer storage/cookie persistence strictly to `mouseup`.
- **Strict Relative Path Tree Matching & Git Status Isolation:** In workspace trees, never check active file highlight via `activeFilePath.endsWith(node.name)` or map git statuses via `gitFilesMap[node.name]`. This causes all files sharing common names (`types.ts`, `index.ts`, `page.tsx`) across different directories to simultaneously highlight and falsely display git modification badges. Index and compare strictly by normalized relative repository path.
- **Scope Search Filtering to Entity Names:** In recursive file trees, never test filter queries against `node.path` when `node.path` contains the full absolute OS filesystem path. Queries for common words ("users", "documents", project name) match every single node and disable filtering. Test queries strictly against `node.name` or workspace-relative path.
- **Non-Blocking Native Dialog Concurrency:** Never invoke synchronous desktop UI dialogs (such as Tkinter's `filedialog.askdirectory` or Win32 file pickers) directly inside an asynchronous web server request handler (`async def`). Modal desktop dialogs completely block the Python `asyncio` event loop while awaiting user interaction, freezing all concurrent sessions, SSE streams, background runners, and channel gateways. Always offload native dialog invocation to a worker thread via `await asyncio.to_thread(_pick_sync)` or drive folder selection via native web file pickers.
- **Stable Identity Keys in Recursive Trees:** In recursive file/directory tree components (`WorkspaceTreeView`, `RecursiveTreeNode`), never use array iteration indices (`key={idx}`) for child nodes. When folders expand, collapse, or dynamically filter on user search queries, index-based keys cause severe DOM reconciliation mismatches, state leakage, and unintended component re-mounts. Always assign stable unique keys derived from normalized file paths (`key={child.path || `${child.name}-${idx}`}`).
- **Workspace Sandboxing & Credentials Exfiltration Guard on IDE Endpoints:** In web IDE endpoints that expose raw filesystem access (`/workspace/file-content`, `/workspace/save-file`), always enforce strict path traversal defenses (`../`, `..\`) and validate target paths against the session's workspace root boundary (`WorkspaceSentinel`). Block access to secret credential stores (`.env`, `.git`, `.ssh`, `credentials`) with explicit 403 Forbidden errors to prevent exfiltration through the browser.
- **Pitfall:** Calling synchronous GUI dialogs in an async route hangs the entire agent daemon for all users/channels until the dialog is closed, while array index keys in file trees cause search filters to glitch and misrender nested folders. Synchronous storage writes in mousemove drag listeners drop frame rates, and substring matching in model/file trees produces widespread false-positive highlights and status badges.

### 9. Real-Time Streaming, Audio Graph & WebSocket Lifecycle Discipline
- **Hardware Mic Stream & AudioContext Leak Defense:** In microphone capture hooks (`useMicrophone`), `startListening()` is asynchronous (`getUserMedia` + `audioWorklet.addModule`). If the component unmounts or `stopListening()` is called while promises are still in flight, guard with `isMountedRef` / cancellation flags and immediately abort: stop all media tracks (`stream.getTracks().forEach(t => t.stop())`) and close the `AudioContext`. On stop, completely disconnect all intermediate nodes (`silentGain`, `highPassNode`, `antiAliasNode`) and close the `AudioWorkletNode` port to release hardware mic access and prevent audio thread leaks.
- **Anti-Aliasing DSP Resampling Filter:** When capturing microphone audio at hardware sample rates (44.1kHz or 48kHz) and downsampling to 16kHz for model ingestion via worklet decimation, always insert a low-pass biquad filter at 7500Hz (`type = "lowpass"`, Q = 0.707) before the downsampler. Without an anti-aliasing low-pass filter, frequencies above the 8kHz Nyquist limit fold back into the audible spectrum, creating severe metallic aliasing artifacts that degrade speech recognition accuracy.
- **De-Clicking Master Gain Ramp & Barge-In Audio Interruption:** When interrupting assistant voice playback (barge-in or manual stop), never instantaneously cut off WebAudio buffer source nodes or set gain to zero. An instantaneous drop in signal amplitude causes an acoustic transient (loudspeaker click/pop artifact). Route all playback through a master `GainNode` and apply a 15ms linear/exponential ramp down (`linearRampToValueAtTime(0.0001, now + 0.015)`) before stopping buffer nodes.
- **Generation Invalidation Counter (Anti-Barge-In Leak):** Guard streaming playback with a monotonic `generationRef` integer incremented on every `stopAudio()`. When asynchronous network chunks arrive or resume promises resolve, compare the chunk's generation against `generationRef.current` and immediately discard stale chunks from cancelled turns so superseded audio never bleeds into new turns.
- **Synchronous Audio Playback Scheduling (Anti-Collision):** Never compute buffer `startTime` after an asynchronous `await audioContext.resume()`. If chunks arrive in bursts, asynchronous yields cause multiple chunks to calculate the exact same `currentTime` offset, resulting in chunk collisions and stuttering audio. Synchronously calculate and advance `nextPlayTimeRef.current` before scheduling, maintaining a jitter buffer lead-time (~150ms) for continuous playback.
- **WebSocket StrictMode Connection Guard:** In React 18/19 StrictMode, effects mount, unmount, and remount in rapid succession. In `useWebSocket`, verify instance identity (`if (wsRef.current !== ws) return;`) inside `onopen`, `onmessage`, `onerror`, and `onclose`. If an old WebSocket closes after a new one has connected, the stale close event must not overwrite `wsRef.current` or toggle connection status to disconnected.
- **Decoupled Callbacks via Mutable Ref:** Never bind WebSocket `connect()` to raw event callback props (`onAudioChunk`, `onTranscript`, `onError`). Pass callbacks through a mutable `callbacksRef` updated on every render so the WebSocket connection remains stable and never re-instantiates or retains stale closures across component re-renders.
- **Transport Heartbeat Ping/Pong & Reverse Proxy Persistence:** In agent WebSocket connections, send a periodic 30-second ping heartbeat (`{ type: "ping" }`) and handle `{ type: "pong" }`. Reverse proxies (Nginx, Cloudflare, tunnels) silently terminate idle TCP sockets after 60 seconds; an active heartbeat prevents silent drops and detects broken connections immediately.
- **Outbound Message Reconnect Queue & Jitter Backoff:** Queue outgoing messages during disconnected or connecting states and automatically flush the queue upon `onopen`. Pair reconnections with full-jitter exponential backoff (e.g. `Math.min(baseDelay * 1.5^retry + jitter, MAX_DELAY)`) and reset the retry counter only after a stable connection duration (>5s) to avoid reconnect storms.
- **Pitfall:** Unbounded async getUserMedia leaves hardware microphones recording indefinitely after page transitions. Instantaneous audio interruption produces jarring speaker pops, while React StrictMode without instance-identity checks triggers duplicate WebSocket loops and disconnection storms.

### 10. Splitter Event Management & Gateway Token Injection
- **Splitter Listener Thrashing (Zero State in Dependency Arrays):** In draggable layout splitter hooks (`useLayoutSplitter`), never include the current `size` in the `useEffect` dependency array when attaching `mousemove` and `mouseup` event listeners. When `size` updates on every pixel drag, the effect violently unbinds and re-binds listeners 60–144 times per second. Keep live dimensions in a mutable ref (`currentSizeRef.current = size`), read the ref in `handleMouseUp` for storage persistence, and exclude `size` from listener registration dependencies.
- **User Selection Suppression During Drag:** When drag resizing panes, disable text selection globally (`document.body.style.userSelect = "none"`) and set active cursors (`col-resize` / `row-resize`), restoring them cleanly on `mouseup` and unmount to prevent accidental text highlighting across editor lines.
- **Universal Gateway Token Injection vs Raw fetch() Bypass:** In web workspaces protected by remote password/gateway access, never issue raw `fetch()` calls directly to backend endpoints. Raw `fetch()` fails to inject `Authorization: Bearer <anara_gateway_token>`, resulting in widespread HTTP 401 Unauthorized errors on workspace tree, file save, and session endpoints. Route all HTTP operations through an unified API helper (`apiRequest()` / `anaraApi`) that automatically injects stored gateway tokens.
- **Metadata-Only IDE LocalStorage Persistence:** In multi-tab code editors, never serialize complete file text contents into `localStorage` on keystrokes. Keystroke serialization rapidly exhausts the browser's 5MB `localStorage` budget (`QuotaExceededError`) and leaks unencrypted proprietary source code into browser storage. Persist only lightweight tab metadata (`isOpen`, `fileName`, `filePath`, `fileExt`, `fileSizeKb`), and lazily re-fetch file content from disk on demand.

### 11. 3D WebGL Avatar, Kinetic Hierarchy & Real-Time Viseme Discipline
- **Kinetic Speed Inversion Guard:** In procedural 3D avatar skeletal blending, never prioritize background animation flags over deliberate user gestures (`const armSpeed = animDriven ? 0 : ...`). If `isGesturing` is true, prioritize gesture execution (`const armSpeed = isGesturing ? safeDelta * 10.0 : animDriven ? 0 : ...`); otherwise, procedural gestures (salute, wave, shy, think, joy) remain completely frozen dead code whenever idle skeletal animations are running.
- **Three.js AnimationMixer Root Cache Purging:** On avatar unmount, calling `mixer.stopAllAction()` alone leaves all skeletal bone bindings and property tracks cached in Three.js's internal mixer dictionary. Always invoke `mixer.uncacheRoot(group.current)` and clear all cached bone and morph mesh arrays to eliminate WebGL memory leaks during scene transitions.
- **R3F useFrame Priority 1 Ordering:** When procedural skeletal transformations or bone rotations override an imported GLTF/VRM animation mixer, always set `useFrame((state, delta) => { ... }, 1)` with explicit priority 1. `@react-three/drei`'s `useAnimations` mixer updates at default priority 0; running procedural overrides at priority 0 creates frame race conditions where procedural arm/neck poses are overwritten by the animation mixer.
- **Allocation-Free 60–144 FPS Render Loops:** Inside `useFrame` animation and speech viseme render loops, strictly eliminate dynamic heap allocations. Never call `Object.entries()`, `Object.keys()`, or iterate ES6 `Set` instances with `for..of` (which allocates a `SetIterator` instance every frame). Iterate static arrays or use `for..in` loops to prevent periodic garbage collection frame drops.
- **WebAudio Synthesizer Resource Tracking:** When procedurally synthesizing music or acoustic alerts via WebAudio (`OscillatorNode`, `AudioBufferSourceNode`), track all scheduled nodes in an array. When `stop()` or barge-in is triggered, stop all scheduled nodes immediately and disconnect the master gain. On natural playback completion, automatically disconnect the master gain to release the audio graph.
- **ARKit Viseme Lateral Spread vs Emotion Smile Conflict:** Phonemes `E` and `I` require lateral stretching of the lips. Never map them to `mouthSmileLeft/Right`, as smile morphs belong to the emotional layer and are filtered out by speech processors. Map `viseme_E` and `viseme_I` to ARKit `mouthStretchLeft` and `mouthStretchRight` for authentic acoustic articulation without distorting emotional expressions.
- **Headless Chrome CDP Diagnostics for Live Localhost Forensics:** When diagnosing user-reported frontend errors on a running dev server where standard browser navigation tools stall or timeout, never guess or ask for manual logs. Launch the native Chrome binary in headless remote debugging mode (`--headless --remote-debugging-port=9222 --disable-gpu <url>`), query `http://127.0.0.1:9222/json` for the page's `webSocketDebuggerUrl`, and connect via a lightweight WebSocket script (Python/Node). Enable `Runtime.enable`, `Log.enable`, and `Page.enable`, and trigger `Page.reload`. Listen for `Runtime.exceptionThrown` (instantly surfacing unimported hooks like `ReferenceError: useRef is not defined` with exact line and stack) and `Log.entryAdded` (surfacing SVG/CSS parser failures). Re-navigate across routes (`Page.navigate`) to verify zero errors before terminating the probe.
- **SVG Arc Flag Binary Discipline:** In SVG path data strings (`d="..."`), arc command flags (`a rx ry angle large-arc-flag sweep-flag dx dy`) must strictly be binary digits `0` or `1`. Typographical errors (such as `02-3-3` instead of `01-3-3` in microphone or indicator paths) violate SVG grammar and trigger browser console exceptions (`Expected arc flag ('0' or '1')`) on every render. Verify all hand-authored or converted path strings against valid arc flag constraints.
- **Encapsulated View State vs Orphaned Parent Setters:** When refactoring sub-views into dedicated child components (e.g. `ProviderDetailView` managing its own internal sub-tab state `providerDetailTab`), ensure parent list and card handlers do not retain orphaned setter calls (`onClick={() => { setSelectedProviderId(p.id); setProviderDetailTab(...) }}`) that throw unhandled `ReferenceError: <setter> is not defined` on card clicks. Parent container click handlers must strictly invoke only state functions declared and managed within the parent scope.
- **Build-Time Type Bypass vs Runtime ReferenceErrors:** When modern bundlers or frameworks skip typecheck validation during rapid production builds (`Skipping validation of types`), unimported React hooks (such as omitting `useRef` from `import React, { ... } from "react"`) or undeclared state setters compile with exit code 0, only to throw fatal `ReferenceError` during client-side hydration or component interaction. Never rely solely on successful bundler output as proof of zero runtime errors; always verify client interaction points via headless browser CDP runtime probes (`Runtime.exceptionThrown`).
- **Heavy 3D Asset Loading Discipline & Graceful Remote Fallbacks:** When rendering photorealistic 3D avatar meshes (e.g. 20–30MB GLB assets) over remote tunnels or constrained networks, never trap visitors behind a blocking `<LoadingScreen>` with a frozen static progress bar (`progress ?? 75`). Provide smooth synthetic progress animation, enforce a strict safety timeout (<= 5s) that automatically dismisses the loading screen and falls back to chat mode if downloading stalls, provide a prominent instant bypass button ("Switch to Chat Mode") that unmounts heavy WebGL rendering, and forward WebGL context creation failures (`CanvasErrorBoundary`) directly into chat mode fallback.

### 12. Command Center Information Architecture, Context Panes, Keyboard Navigation & Lazy Workspace Tree
- **Lazy Workspace Tree (Anara Parity):** Never serve a full recursive tree from the backend. Return root-level entries only; expand directories on demand via a `/tree/children` endpoint. See `references/lazy-workspace-tree.md`.
- **Chat as Unified Command Center with Docked Context Panes (Anti-Route Fragmentation):** In developer agent workspaces (Cursor, VS Code, Anara standard), chat and prompt composer are the home surface. Never isolate code editors, terminal shells, or diff viewers into disparate routes or standalone pages that sever conversation context. When a file is opened or terminal toggled, the workspace splits into docked contextual side-panes (e.g. 50/50 split on desktop) directly alongside the chat timeline. Users can inspect diffs, edit source code, and run terminal commands while keeping active dialogue in full view. Dismissing the pane smoothly returns chat to 100% width.
- **Real-Time Single-Line Activity Status Stack (Anti-Spam Tool Progress):** When an agent executes tools (terminal commands, file patches, searches), never flood the transcript with raw tool output dumps or oversized boxes. Pinned above the composer, render a single-line Activity Status Stack (`> executing <toolName> <summary>... [Stop]`) featuring a 1px hairline border, animated pulse, and quick interrupt button (`Ctrl+C` or click). Upon completion, fold execution details into compact hairline accordion pills with chevron disclosure (`Edit file.ts +12 -3`, `Run git status`).
- **Keyboard-Driven Workstation & Quick Command Palette (`Ctrl+K` / `Ctrl+P`):** Provide an instant floating Command Palette (`Ctrl+K`, `Ctrl+P`) with backdrop blur, hairline border, keyboard arrow navigation (`↑`/`↓`), and Enter execution. Expose high-frequency workstation actions (New chat `Ctrl+N`, toggle docked editor `Ctrl+\`, toggle terminal `Ctrl+``, switch model, switch workspace, clear transcript) so power users can navigate without touching the mouse.
- **Custom Fast Tooltip Hygiene (Anti-Browser Native Title Lag):** Strictly avoid native HTML `title="..."` tooltips due to their 500ms delay and rigid platform styling. Implement custom tooltips with warm states (200ms initial delay, 0ms for adjacent siblings within 300ms) and hotkey badges (`TipKeybindLabel`). Never attach redundant tooltips to buttons whose text labels are already visible (e.g. don't tooltip "Save" with "Click to save").
- **Docked Context Inspector vs Floating Modal HUD:** In autonomous coding agents, floating heads-up display (HUD) cards with saturated neon gradients and heavy drop shadows are an amateur anti-pattern that occludes active conversation and IDE code. Autonomous agents prioritize docked, split-pane context surfaces (Chat Stream + Context Pane for Diffs/Files/Terminal). If a glanceable HUD is retained for multimodal voice interaction (displaying quick weather, document previews, or image galleries over a 3D avatar canvas), it must strictly follow Liquid Glass discipline: cosmic obsidian `#060913/90`, `backdrop-blur-xl`, hairline borders (`border-white/[0.08]`), zero raw emojis, accessible semantic buttons, and global Escape key listeners with input element guards.
